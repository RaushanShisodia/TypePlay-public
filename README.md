# TypePlay — Free Typing Website

**TypePlay is a free typing website to learn touch typing with 110 lessons, typing tests, and 18 games. No account needed.**

🌐 **Official Website:** https://typeplay.org

### Features
- 110 step-by-step touch typing lessons
- Typing tests (WPM, accuracy, history)
- 18 typing games
- Progress tracking saved locally — no account needed
- Parent dashboard, lessons for beginners, kids, schools
